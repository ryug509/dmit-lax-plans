## 买之前先定线路，别先定核数

美国 VPS 到中国大陆的访问质量，主要由回程线路决定，而不是 CPU 核数。所以选型顺序建议反过来：先确定你的用户在哪，再挑线路，最后才在对应线路里选内存和硬盘档位。

- 用户主要在中国大陆，或者你自己就要频繁从国内 SSH、传文件、跑后台：优先看带 CN2 GIA 的线路。
- 用户以移动、联通宽带为主，预算又没到 CN2 GIA 那一档：看 CMIN2 / AS9929 这类优化线。
- 用户基本在海外，只是需要一个美国节点跑备份、下载、API：选国际 BGP 线路，同价位流量能给到几倍。

DMIT 把这三类需求做成了三条独立产品线，机房在洛杉矶、香港、东京都有，本文重点讲美国部分。

## Premium、Eyeball、Tier 1 到底差在哪

DMIT 的命名规则很直白，三条线对应三种网络定位：

**Premium（Pro）** 是旗舰线。它在 Tier 1 的基础上叠加 Premium Transit 和中国电信 CN2 GIA，电信去程走 CN2 GIA，联通去程直连 AS4837，移动去程经香港移动，三网回程走 CN2 GIA。这条线面向中国大陆和亚太访问优化，也是价格最高的一档。

**Eyeball（EB）** 是中间档。电信回程在 AS9929 和 AS58807 之间做负载均衡，联通主要走 AS9929，移动主要走 AS58807（CMIN2）。线路档次比 Pro 低一点，但同价位给的月流量通常更多，一个明显例子是 TINY 档：Pro 给 1TB，EB 给 1.5TB。

**Tier 1（T1）** 是国际线路，不针对中国大陆做优化。它的卖点是便宜、端口大、流量多——入门年付不到 40 美元，同样 1核1G 的 TINY 月流量给到 2TB、端口标称 4Gbps。如果你的业务用户根本不在国内，把钱花在 CN2 GIA 上没有意义。

一个容易被忽略的点：DMIT 官网对线路只承诺"合理努力"级别，实际延迟和路由受你所在地区、运营商和机房当时负载影响。下单前建议用官方 Looking Glass 或测试 IP 自己 ping 一遍，Pro 和 T1 各有一条测试线路，先测再付钱比看测评靠谱。

## 下单前必须知道的几条限制

有几个细节不看清楚，买回来容易后悔。

**流量是双向计的。** DMIT 洛杉矶的流量按去程加回程一起算，不是只算单向。月流量 1TB 听起来不小，但如果你的站点以大文件下载为主，实际可用量会比你按单向估的少一半。

**超量不停机，但会限速。** 这是 DMIT 比较实用的一条规则：流量跑完之后服务不会停，而是降到固定带宽继续跑。T1 系列降速后还有 100Mbps 到 500Mbps，Pro 和 EB 则只有 4Mbps 到 10Mbps——Pro 用户跑超之后基本只能维持 SSH 和轻量后台，别指望还能继续提供服务。

**AS3 平台官方仍在提示"持续优化阶段"。** 官网在 AS3 定价页写明，该平台的磁盘性能和 SLA 可能低于成熟平台，正式业务建议先测再上，并做好异地备份。介意这一点的，可以看 AN4、AN5 平台的同档产品，价格更高一些。

**原生 IP 不等于所有平台都能解锁。** 多个第三方测评提到 DMIT 的 IP 属于原生类型、流媒体解锁情况不错，但商家本身不做任何解锁保证，平台风控策略一变结果就会变。把"能解锁某服务"当成购买理由，风险自担。

## 购买流程：从注册到付款

流程本身不复杂，DMIT 支持支付宝、微信、PayPal 和信用卡，国内用户不需要折腾外币卡。

1. 在产品页选定线路、套餐、机房和计费周期。优惠码在结算页填写，不能用在不匹配的产品线或周期上。
2. 结算页有 Validate Code 按钮，填完码点一下验证，折后价格会实时刷新。DMIT 的促销码通常绑定具体产品线和付款周期，填错会直接提示无效。
3. 注册账号时建议用常用邮箱，开通信件和续费提醒都走这里。
4. 付款完成后进入产品控制面板，可以重装系统、查看流量、管理 IP 和账单。

如果只是想先摸一摸线路，月付起步是更稳的做法。T1.TINY 月付 $6.90、Pro/EB 月付 $10.90，试一个月再决定要不要转年付，比一上来就压年付划算。

## 换 IP、退款和产品线变动

**换 IP。** IP 被墙的情况下，第三方资料普遍提到每 15 天可以免费更换一次，其他情况需要付费，多家测评写的价格是 $5 一次。这个规则属于会调整的类型，买之前建议在官网服务条款里确认一遍。

**154 开头的 IP 会有额外费用。** 官方公告提到，为了消化外部 IP 租赁成本，从 2026 年 12 月 1 日起，继续保留 154 开头 IPv4 的产品每月加收 1 美元；不想付这笔钱，可以在控制面板的网络选项卡里免费换到自购 IP。

**退款走自助通道。** 产品控制面板的计费选项卡里有退款按钮，比开工单快。受支付网关限制，账单超过 6 个月的通常只能退到账户余额，6 个月内的可以原路退回。

**产品线会被调整。** 过去一年里 DMIT 先后公告过东京 Eyeball 系列和香港 EBv2 系列停服，按剩余价值退款并提供折扣码转购其他产品。这不是 DMIT 独有的问题，但对准备一次性压三年、五年的用户来说，是个值得记住的变量——长周期预付前，最好确认一下这条产品线的长期规划。

## 不同需求怎么选，给个直接的结论

- **国内建站、对国内访问速度有要求**：Pro 系列，TINY 起步够跑轻量站和后台，有正式流量再上 STARTER 或 MINI。
- **移动、联通宽带用户为主，想要更多流量**：EB 系列，同价位流量比 Pro 多，季付及以上可以试试 8 折码。
- **预算优先，用户在国外，或者只是要个中转、落地、备份节点**：T1 系列。WEE 年付 $36.90 是整个洛杉矶最低的入场价，T1.TINY 月付 $6.90 适合先试。
